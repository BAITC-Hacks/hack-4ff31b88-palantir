# Проверка сборки агента

Дата: 23.09.2026. Основа интеграции — main `b25c344362b1f8e82b6580394ebe9151b656b5de`.
Модули `data/` и `model/baseline_nwp.py` сохранены без изменений.

Проверено:

- Создана отдельная пустая Python-среда, зависимости установлены через pip.
- `pip check`: ошибок совместимости зависимостей нет.
- 19 unittest-проверок анализа, виртуального календаря, отсечения будущих
  наблюдений, отклонения будущей модели, интеграции погоды и `power_pred`, графиков.
- Полный прогон 31.01–27.02 с реальным архивом ECMWF/GFS и встроенным бейзлайном.
- Полный прогон с реальным архивом и `model.baseline_nwp.predict` Человека 2.
  В каждом: 28 принятых запусков, 672 часа февраля станции, 648 замен.
- Создание CSV, JSON/JSONL, SQLite и графика. График без фактов явно подписан.

В этой среде репозиторий получен через авторизованный GitHub-коннектор.
Команда `git clone` приватного репозитория через локальный Git отдельно не проверена:
локальная авторизация Git отличается от подключения GitHub в приложении.
Установка зависимостей, тесты и запуск выполнены в новой виртуальной среде.

Основные версии проверенной среды: Python 3.12, pandas 3.0.6, numpy 2.5.3,
requests 2.34.2, pyarrow 25.0.1, matplotlib 3.11.2, openai 3.19.0.
Это журнал проверки, а не требование для артефакта будущей ML-модели:
её владелец должен зафиксировать совместимые версии.

Ещё не подтверждено:

- Обученная ML-модель: пока доступен только командный бейзлайн.
- Точность на феврале и график против факта: фактов февраля в CSV нет.
- Реальный LLM-вызов: без API-ключа использовано локальное резюме; ошибки LLM
  проверены тестом резервного варианта.
- Сдвиг SCADA +7 и реальная задержка поступления наблюдений: нужны подтверждение
  организаторов и команды. Использован текущий сдвиг `meta.json`.
- Время публикации погоды проверяется по правилу модуля данных, не по точным
  меткам отдельных NWP-выпусков. Координаты второй турбины в `data/config.py`
  пока совпадают с первой и помечены TODO — это остаётся задачей владельца данных.

Смена прогноза по сравнению с предыдущим выпуском не является метрикой точности.
Качество бейзлайна за январь находится в `model/metrics_baseline.csv`; его значения
нельзя подписывать как качество на тестовом феврале.
